# AI FAQ Chatbot

A lightweight chatbot style frontend project built with HTML, CSS, and JavaScript.

## Features
- Chat style user interface
- FAQ based automated responses
- Dark mode toggle
- Responsive layout
- Clean and simple design

## Tech Stack
- HTML
- CSS
- JavaScript

## What I learned
- DOM manipulation
- Event handling
- Responsive UI design
- Basic chatbot logic

## How to run
Open `index.html` in the browser.
